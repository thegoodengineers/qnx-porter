# fmt for QNX 8.0

Generated by [qnx-porter](https://github.com/thegoodengineers/qnx-porter) from its automatic port of
fmt `11.0.2` (https://github.com/fmtlib/fmt.git). On a QNX 8.0 x86_64 target (QEMU) 17/20 of its own tests passed. Full report:
`ports/fmt/REPORT.md` in qnx-porter.

## Build
```bash
source ~/qnx800/qnxsdp-env.sh
git clone --depth 1 --branch 11.0.2 https://github.com/fmtlib/fmt.git fmt
QNX_PROJECT_ROOT="$(pwd)/fmt" make -C build-files/ports/fmt install JLEVEL=4
```

## QNX changes, each with its reason
| rule | reason |
|---|---|
| link-libregex | `regfree` (POSIX <regex.h>) is in QNX's libregex, not in libc as on Linux: link with -lregex. |
