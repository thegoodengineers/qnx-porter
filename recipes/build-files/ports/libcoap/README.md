# libcoap for QNX 8.0

Generated by [qnx-porter](https://github.com/thegoodengineers/qnx-porter) from its automatic port of
libcoap `v4.3.5` (https://github.com/obgm/libcoap.git). On a QNX 8.0 x86_64 target (QEMU) its test suite did not run there (see the port's report). Full report:
`ports/libcoap/REPORT.md` in qnx-porter.

## Build
```bash
source ~/qnx800/qnxsdp-env.sh
git clone --depth 1 --recurse-submodules --shallow-submodules --branch v4.3.5 https://github.com/obgm/libcoap.git libcoap
QNX_PROJECT_ROOT="$(pwd)/libcoap" make -C build-files/ports/libcoap install JLEVEL=4
```

## QNX changes, each with its reason
| rule | reason |
|---|---|
| link-libsocket | `getifaddrs` is in QNX's libsocket, not in libc as on Linux: link with -lsocket. |
