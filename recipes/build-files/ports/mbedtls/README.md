# mbedtls for QNX 8.0

Generated by [qnx-porter](https://github.com/thegoodengineers/qnx-porter) from its automatic port of
mbedtls `v3.6.2` (https://github.com/Mbed-TLS/mbedtls.git). On a QNX 8.0 x86_64 target (QEMU) 130/130 of its own tests passed. Full report:
`ports/mbedtls/REPORT.md` in qnx-porter.

## Build
```bash
source ~/qnx800/qnxsdp-env.sh
git clone --depth 1 --branch v3.6.2 https://github.com/Mbed-TLS/mbedtls.git mbedtls
QNX_PROJECT_ROOT="$(pwd)/mbedtls" make -C build-files/ports/mbedtls install JLEVEL=4
```

## QNX changes, each with its reason
| rule | reason |
|---|---|
| link-libsocket | `__inet_pton` is in QNX's libsocket, not in libc as on Linux: link with -lsocket. |
