# flac for QNX 8.0

Generated by [qnx-porter](https://github.com/thegoodengineers/qnx-porter) from its automatic port of
flac `1.4.3` (https://github.com/xiph/flac.git). On a QNX 8.0 x86_64 target (QEMU) 7/10 of its own tests passed. Full report:
`ports/flac/REPORT.md` in qnx-porter.

## Build
```bash
source ~/qnx800/qnxsdp-env.sh
git clone --depth 1 --branch 1.4.3 https://github.com/xiph/flac.git flac
QNX_PROJECT_ROOT="$(pwd)/flac" make -C build-files/ports/flac install JLEVEL=4
```

## QNX changes, each with its reason
| rule | reason |
|---|---|
| wcswidth-compat | QNX 8.0's libc has wcwidth() but no wcswidth(). POSIX defines wcswidth(s, n) as the sum of wcwidth() over the first n characters of s, or -1 if any is not printable; a small header (-included in every compile) implements exactly that on top of QNX's wcwidth(). |

Compat headers in `qnx-compat/` (qnx-wcswidth.h) are `-include`d by common.mk.
