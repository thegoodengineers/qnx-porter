# libsrtp for QNX 8.0

Generated by [qnx-porter](https://github.com/thegoodengineers/qnx-porter) from its automatic port of
libsrtp `v2.6.0` (https://github.com/cisco/libsrtp.git). On a QNX 8.0 x86_64 target (QEMU) 8/12 of its own tests passed. Full report:
`ports/libsrtp/REPORT.md` in qnx-porter.

## Build
```bash
source ~/qnx800/qnxsdp-env.sh
git clone --depth 1 --branch v2.6.0 https://github.com/cisco/libsrtp.git libsrtp
QNX_PROJECT_ROOT="$(pwd)/libsrtp" make -C build-files/ports/libsrtp install JLEVEL=4
```

## QNX changes, each with its reason
| rule | reason |
|---|---|
| link-libsocket | `socket` is in QNX's libsocket, not in libc as on Linux: link with -lsocket. |
