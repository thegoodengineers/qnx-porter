# wolfssl for QNX 8.0

Generated by [qnx-porter](https://github.com/thegoodengineers/qnx-porter) from its automatic port of
wolfssl `v5.7.4-stable` (https://github.com/wolfSSL/wolfssl.git). On a QNX 8.0 x86_64 target (QEMU) 1/1 of its own tests passed. Full report:
`ports/wolfssl/REPORT.md` in qnx-porter.

## Build
```bash
source ~/qnx800/qnxsdp-env.sh
git clone --depth 1 --branch v5.7.4-stable https://github.com/wolfSSL/wolfssl.git wolfssl
QNX_PROJECT_ROOT="$(pwd)/wolfssl" make -C build-files/ports/wolfssl install JLEVEL=4
```

## QNX changes, each with its reason
| rule | reason |
|---|---|
| no-werror | Warning -Wstringop-overflow= is promoted to an error by the project's -Werror. Keep it a warning (still printed in the build log) instead of editing the library's code; QNX's headers and qcc raise warnings a glibc build does not. |
| link-libsocket | `recv` is in QNX's libsocket, not in libc as on Linux: link with -lsocket. |
