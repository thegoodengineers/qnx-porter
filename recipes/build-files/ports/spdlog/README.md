# spdlog for QNX 8.0

Generated by [qnx-porter](https://github.com/thegoodengineers/qnx-porter) from its automatic port of
spdlog `v1.15.0` (https://github.com/gabime/spdlog.git). On a QNX 8.0 x86_64 target (QEMU) its test suite did not run there (see the port's report). Full report:
`ports/spdlog/REPORT.md` in qnx-porter.

## Build
```bash
source ~/qnx800/qnxsdp-env.sh
git clone --depth 1 --branch v1.15.0 https://github.com/gabime/spdlog.git spdlog
QNX_PROJECT_ROOT="$(pwd)/spdlog" make -C build-files/ports/spdlog install JLEVEL=4
```

## QNX changes, each with its reason
| rule | reason |
|---|---|
| qnx-source | C++ sees only `struct stat`, not the POSIX function `stat()`: in strict -std=c++NN mode QNX's headers hide POSIX extensions (here sys/stat.h declares stat() only under __EXT_POSIX1_198808). -D_QNX_SOURCE exposes them, as _GNU_SOURCE does on glibc. |
