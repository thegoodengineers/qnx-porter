# Licences of the ported libraries

Generated by `scripts/sbom.py`; do not edit. Each `ports/<lib>/sbom.spdx.json` is an SPDX 2.3 document for the upstream package at the commit we ported, with our `qnx.patch` and its SHA-256. The licence is the declared licence that ScanCode Toolkit (scancode-toolkit-32.5.0) reports in its summary over the library's top-level and first-level licence, copying, copyright, notice and README files. Only those files were scanned, not the source tree, so a licence stated only in source headers is not seen here. `NOASSERTION` means ScanCode detected nothing. Where ScanCode's expression is not valid SPDX (for example a bare exception such as `LLVM-exception`), the SBOM's `licenseDeclared` is `NOASSERTION` and its `licenseComments` and this table keep the expression as found.

Read the expressions as scanner findings. ScanCode joins licences it finds in one file with `AND`, also when the file offers a choice: Mbed TLS's LICENSE says Apache-2.0 OR GPL-2.0-or-later, and the table shows `AND`. README files add licences they merely mention. A flag means a copyleft licence was detected, so check that library's licence files before deciding anything from it.

Of 61 libraries: 9 have a GPL or AGPL licence in their expression (GPL family), 7 an LGPL licence, 9 a weak copyleft licence (LGPL, MPL, EPL or CPL), and 1 with no detected licence.

Why this matters on QNX. QNX products are commonly shipped as one system image in which libraries are linked statically or delivered as shared objects alongside proprietary code. The GPL applies its terms to a distributed work based on the GPL-licensed code, which then has to be offered with its corresponding source under the GPL. The LGPL allows linking from code under other terms but requires that recipients can replace the LGPL library with a modified version; with static linking that usually means also providing the object files needed to relink. MPL and EPL obligations apply to the licensed files themselves, so changes to those files, including our `qnx.patch`, are distributed as source. An expression with `OR` offers a choice of licence; `AND` means all listed terms apply, often to different parts of the package, such as a library and its command-line tools. This page is scanner output for engineering triage, not a legal review.
